## 4. 关键用户场景测试

### 场景1：新用户首次使用（高优）
1. 用户打开小程序 → 首页展示引导
2. 点击"立即开始测评" → 完成30道题 → 查看结果
3. 查看TOP1组合详情 → 了解专业方向
4. 体验会员功能被引导 → 考虑是否开通

### 场景2：选科查询决策（高优）
1. 用户有初步选科想法 → 查询页勾选科目
2. 查看可报组合列表 → 逐个查看详情
3. 查询目标大学的选科要求
4. 查询目标专业的开设院校

### 场景3：成绩追踪分析（中优）
1. 每次考试后录入成绩
2. 查看成绩趋势和排名变化
3. （会员）查看智能学习建议
4. （会员）根据成绩预估录取概率

### 场景4：会员转化路径（高优）
1. 免费用户使用基础功能 → 产生信任
2. 点击会员功能 → 看到模糊内容 → 激发好奇心
3. 进入会员中心 → 对比权益 → 考虑价格
4. 选择套餐 → 完成支付 → 解锁全部功能
