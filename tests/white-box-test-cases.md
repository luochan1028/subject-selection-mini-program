## 4. 性能测试点（白盒视角）

### 4.1 算法复杂度

| 模块 | 时间复杂度 | 空间复杂度 | 验证方式 |
|------|-----------|-----------|----------|
| 测评计算 | O(n) n=题目数 | O(1) 固定维度 | 30题计算 < 100ms |
| 组合筛选 | O(n) n=组合数 | O(n) 结果数组 | 20个组合筛选即时响应 |
| 搜索过滤 | O(n) n=数据量 | O(n) 结果数组 | 1000条数据搜索 < 500ms |
| 深拷贝 | O(n) n=属性数 | O(n) 新对象 | 一般对象拷贝 < 1ms |

### 4.2 内存泄漏风险点

| 风险点 | 检查方式 |
|--------|----------|
| 定时器未清理 | 所有setTimeout/setInterval有对应清理 |
| 事件监听未移除 | 页面onUnload中移除监听 |
| 全局变量累积 | 不使用全局变量存储大量数据 |
| 闭包引用 | 避免循环引用导致无法GC |
